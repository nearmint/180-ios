# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities privately through GitHub: open the **Security** tab of this repository and click **Report a vulnerability**. This uses GitHub private vulnerability reporting; only the maintainers can see the report.

Include a description of the issue, the steps to reproduce it and the affected version or commit. You will get an acknowledgement as soon as possible, and we will keep you informed until the issue is resolved.

## Supported versions

Only the latest code on the `main` branch is supported.
